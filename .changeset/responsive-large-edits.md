Keep the page responsive when you paste many lines of text into a text box. Each pasted line costs the same however many came before it, so 30,000 lines go in within about a second. Pasted HTML paragraphs go in the same way. When more than 250 slides are selected, the toolbar no longer checks **Layout** and **Reset** on every selected slide.
