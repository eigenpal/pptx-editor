Side-panel fields apply each valid entry while you type, so the slide shows the change at once. This includes format, Animations, Chart, and Diagram fields. One field edit is one undo step, and Escape restores the start value. Number fields step with Arrow Up and Arrow Down. The Transparency slider writes while it moves. The outline **Width** field sits on one row with its label, as the other outline controls do.
