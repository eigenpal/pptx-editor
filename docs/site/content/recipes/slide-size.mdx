Use the `setSlideSize` command to change the size of every slide. The editor scales the content to fit and records the change as one undo step.

## Switch to 4:3

This helper accepts an open `PptxEditorInstance`. Sizes are in EMU (914400 per inch):

```ts
import type { PptxEditorInstance } from '@pptx-editor.dev/core/editor';

export function setStandardSize(editor: PptxEditorInstance) {
  const result = editor.exec({
    type: 'setSlideSize',
    width: 9_144_000, // 10 in
    height: 6_858_000, // 7.5 in
  });
  if (!result.ok && !result.noop) throw new Error(result.reason);
}
```

Each side must be from 914400 to 51206400 EMU (1 to 56 inches). A size out of that range is refused with `errors.slideSizeRange`. The current size gives a `noop` result.

## Choose what happens to the content

By default, `content` is `'scale'`. The editor then scales the content by the smaller of the width and height ratios and centers it on the new slide:

- Boxes of shapes, pictures, groups, tables, and charts on the slides, layouts, and masters.
- Table column widths and row heights.
- Text sizes, character spacing, spacing in points, indents, tab stops, and text and cell insets, including the text styles of the masters and the presentation.

Line widths and effect distances keep their values.

Set `content: 'keep'` to change only the size. Every box then stays where it is, so content can extend past a smaller slide.

## Let users pick a size

The default editor shows the slide size in **File** > **Page setup**. Users pick a preset (Widescreen, Standard, A4, or Letter) or type a custom size, choose the orientation, and choose whether the content scales. For the dialog's fields, see [Dialogs reference](/docs/customization/reference/dialogs).
