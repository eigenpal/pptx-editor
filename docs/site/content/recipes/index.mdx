These recipes combine the shared editor APIs into application tasks. They accept an existing editor, so you can reuse them across React and Vue.

- [Find and replace text](/docs/recipes/replace-text): replace matching text as one undo step.
- [Change the slide size](/docs/recipes/slide-size): resize every slide and scale the content to fit.
- [Adjust a preset shape](/docs/recipes/shape-adjustments): change the corner radius, arrowhead, or other adjust values.
- [Fill with a pattern or picture](/docs/recipes/pattern-picture-fills): set a preset pattern or a picture on shapes and slide backgrounds.
- [Load and save presentations](/docs/guides/loading-and-saving): connect browser files and server storage.
- [Insert and format images](/docs/guides/images): insert bytes and add alt text.
- [Undo history](/docs/guides/undo-history): group multiple commands into one user action.

For server-side automation, use the [Editing API](/docs/editor-api).
