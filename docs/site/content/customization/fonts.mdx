Pass font sources through `fonts` so the editor can measure and render text with the same bytes. CSS `@font-face` rules alone do not configure layout.

## Use Google Fonts

Install `@docx-editor.dev/fonts` alongside your [React or Vue adapter](/docs/frameworks). This browser example loads packaged substitutes and Google Fonts, including Arabic and CJK fallback faces:

<FrameworkTabs>
<Framework value="react">

```tsx
import { PptxEditor, useFonts } from '@pptx-editor.dev/react';
import { packagedFonts } from '@docx-editor.dev/fonts';
import { googleFonts } from '@docx-editor.dev/fonts/google';
import '@pptx-editor.dev/react/styles.css';

export function FontEditor({ bytes }: { bytes: Uint8Array }) {
  const fonts = useFonts(packagedFonts(), googleFonts({ cjk: true }));
  return <PptxEditor document={bytes} fonts={fonts} />;
}
```

</Framework>

Google Fonts makes network requests when the deck needs a catalog family. Arabic text requests Amiri. CJK text requests a regional Noto Sans fallback. Large CJK faces load in the background and can change line breaks when they arrive. Use `googleFonts({ allow: ['Amiri', 'Lato'] })` to limit the catalog families you permit.

Without `fonts`, the editor uses permitted embedded fonts and packaged substitutes without network requests. For server-side output, configure [PDF fonts](/docs/export/pdf/fonts) separately.

## Load application fonts

Host your font files and load them with `loadFonts()`. Include each weight and style the deck uses.

```ts
// brand-fonts.ts (in a Vue app, import loadFonts from '@pptx-editor.dev/vue')
import { loadFonts } from '@pptx-editor.dev/react';

export function loadBrandFonts() {
  return loadFonts({
    sources: [
      {
        url: '/fonts/BrandSans-Regular.ttf',
        family: 'Brand Sans',
        weight: 400,
        style: 'normal',
      },
      {
        url: '/fonts/BrandSans-Bold.ttf',
        family: 'Brand Sans',
        weight: 700,
        style: 'normal',
      },
    ],
  });
}
```

`loadFonts()` returns admitted `sources` and typed `failures`. One failure does not discard other faces.

<FrameworkTabs>
<Framework value="react">

```tsx
import { useEffect, useState } from 'react';
import { PptxEditor } from '@pptx-editor.dev/react';
import { loadBrandFonts } from './brand-fonts';

type Fonts = Awaited<ReturnType<typeof loadBrandFonts>>;

export function FontEditor({ bytes }: { bytes: Uint8Array }) {
  const [fonts, setFonts] = useState<Fonts>();
  const [failed, setFailed] = useState(false);
  useEffect(() => {
    let disposed = false;
    loadBrandFonts().then(
      (value) => {
        if (disposed) return;
        if (value.failures.length > 0) setFailed(true);
        else setFonts(value);
      },
      () => !disposed && setFailed(true)
    );
    return () => {
      disposed = true;
    };
  }, []);
  if (failed) return <p role="alert">Fonts failed to load.</p>;
  if (!fonts) return <p role="status">Loading fonts…</p>;
  return <PptxEditor document={bytes} fonts={fonts} />;
}
```

</Framework>

| `loadFonts()` option | Use |
| --- | --- |
| `sources[].url` | Application-selected font URL. |
| `sources[].family` | Family the bytes supply. |
| `sources[].weight` | Integer from `1` through `1000`. |
| `sources[].style` | `normal` or `italic`. |
| `sources[].hash` | Optional `sha256:` hash. Mismatched bytes are refused. |
| `sources[].faceIndex` | Collection face index. Default `0`. The editor measures face `0` only and refuses others with `unsupportedFaceIndex`. |
| `cacheName` | Cache API bucket. Default `docx-editor-fonts`, shared with DOCX Editor on the same origin. |
| `fetcher` | Fetch implementation. Default global `fetch`. |
| `maxFontBytes` | Per-source byte limit. Default is the engine hard limit (64 MiB). |
| `signal` | Cancels the request. The operation rejects with `signal.reason`. |

Failure reasons are `networkError`, `httpError`, `hashMismatch`, `overLimit`, `emptyResponse`, `invalidRequest`, and `malformed`. Cached entries are validated before use. For bytes you hold, `createFontSource` returns a source or a typed failure.

## Choose a font source

`fonts` accepts a `FontConfigurationFragment`, a complete `FontConfiguration`, or a `FontResolver`. Combine origins with `useFonts()` or `composeFontConfiguration`.

| Source | Use |
| --- | --- |
| `packagedFonts()` | Metric-compatible substitutes for common defaults, from the package's own bytes. |
| `customFonts()` | Your own hosted families. |
| `googleFonts({ allow })` | Pinned Google Fonts catalog. `allow` limits downloads. `onFailure` reports failed downloads. |
| `FontResolver` | Loads approved faces after the deck requests families. Mark it with `defineFontResolver` when it sits in a list. |
| Embedded deck fonts | Load automatically when usable (`p:embeddedFontLst`; the font's embedding permissions are honored). |

Earlier sources win for the same family, weight, and style. A supplied face wins over a substitution.

| Configuration field | Use |
| --- | --- |
| `sources` | Validated bytes with family, weight, and style. |
| `supportedFamilies` | Selectable families. The font picker lists them, and `useFontFamily().options` gives them to your own picker. Listing performs no fetch. |
| `substitutions` | Maps a requested face to a supplied face. `snapshot().substitutedFonts` reports the target family. |
| `maxFontBytes` | Per-face admission limit. |
| `defaultFont`, `language`, `epoch` | Accepted for DOCX Editor compatibility. A slide's text size comes from the deck's text styles, so these do not change layout. |

A `FontResolver` receives `families`, `defaultFamily`, and optional `signal` and `resolvedFaces`. It returns a configuration, a fragment, or `undefined`. Map family names to URLs through your own lookup, and pass `signal` to your fetch calls so cancellation stops network work.

`families` contains up to 64 requested names, including theme fonts, explicit typefaces, and script fallbacks. `defaultFamily` is the theme's minor Latin font.

### Render Chinese, Japanese, and Korean text

Use `googleFonts({ cjk: true })` as shown above for regional Noto Sans faces. For self-hosted CJK fonts, install `@docx-editor.dev/fonts-cjk` and import `cjkFonts` from its `/browser` entry. Pass `cjkFonts()` to `useFonts()` instead of enabling Google's CJK source. Choose one CJK source to avoid downloading both.

A missing font uses an available face with suitable glyphs. Substitution can change line breaks. See [Chinese, Japanese, and Korean text](/docs/guides/east-asian-text).

## Replace fonts

A new `fonts` prop value calls `setFonts()`. The instance, deck, selection, undo history, and collaboration session stay. On a `createPptxEditor` instance, call it directly.

```ts
await editor.setFonts(nextFonts);
// Remove host-supplied faces when their permission expires.
await editor.setFonts(undefined);
```

| Change | Result |
| --- | --- |
| New fonts | Cancels the previous resolver. Current faces paint until the new ones are ready. |
| New fonts that fail or supply nothing usable | Removes the previous host faces anyway. Text uses the packaged substitutes unless the deck embeds faces. `onFontError` reports the failure. |
| `undefined` | Removes host faces at once. |

Keep `fonts` stable across renders, because each new value resolves fonts again. `useFonts()` returns one value for the component's life.

## Which face measures each family

| Rank | Source                                                      |
| ---- | ----------------------------------------------------------- |
| 1    | Embedded deck faces                                         |
| 2    | Host faces, in origin order (`fonts`)                       |
| 3    | Host substitutions whose target face a host origin supplied |
| 4    | Packaged substitutes from `@docx-editor.dev/fonts`          |
| 5    | Fallback measurement                                        |

A lower rank still serves a style that a higher rank lacks. `snapshot().substitutedFonts` lists the families that measure with another face, and `PptxEditor.FontNotice` shows them.

## Configure loading

A deck that opens waits at most 2 seconds for its fonts: the text engine, the packaged substitutes, and the faces of your `fonts` origins. Faces that arrive later install when they land, and the slides lay out again. A slow or blocked font download never holds the loading screen.

Browser font registration has a separate 2-second limit. If registration stalls, the editor opens with available browser faces. Late faces remain registered and display when the browser finishes loading them.

A deferred font chain stops after 256 arrivals and reports a font error. Faces already received remain available. This limit prevents cyclic or endless resolver answers from blocking browser input.

Until the text engine starts, the deck measures text with a fixed measurer and paints with the faces the browser already has. Embedded faces and your `fonts` faces paint when the text engine starts. The shapes whose text you edit before then fit again when the text engine starts. Other shapes keep the fit that the file has, also when you move them. The new fit is one undo step of its own, so the first undo gives back the estimated fit.

When the text engine cannot start, for example because a Content Security Policy blocks WebAssembly, the fixed measurer and the browser's faces stay, and `onFontError` reports why.

`editor.fontMeasurement()` says which measurer the deck uses and whether fonts are still on the way. In this sample, `editor` is the `PptxEditorInstance` that `onReady` gives you. In React, `usePptxEditor()` returns it; in Vue, `usePptxEditor().value` holds it. A change of `resolving` publishes an editor state change, so read the value again in a `useEditorState` selector or a `subscribe` callback:

```ts
const { measurer, resolving } = editor.fontMeasurement();
// measurer: 'shaped' | 'fixed'.
// resolving: true while fonts arrive. Late fonts count for at most 10 seconds.
```

While `resolving` is `true`, `snapshot().substitutedFonts` stays empty, so the font notice does not show for fonts that are still loading.

To load an origin's faces after the first paint, wrap it in `deferFonts()`. The deck opens with the other faces and lays out again when these arrive.

```tsx
import { deferFonts, useFonts, type FontOrigin } from '@pptx-editor.dev/react';
import { packagedFonts } from '@docx-editor.dev/fonts';

export function useDeckFonts(brandFonts: FontOrigin) {
  return useFonts(packagedFonts(), deferFonts(brandFonts));
}
```

`deferFonts()` is also exported from `@pptx-editor.dev/vue` and `@pptx-editor.dev/core/editor`. A resolver can also return late faces on its `deferred` field.

## Report failures

`onFontError` (React) and the `fontError` event (Vue) receive an `EditorFontError` with a `code`, the face `request` when there is one, and a `diagnostic`. Without a handler, the editor prints one warning for each failure.

## Add faces to the current fonts

`editor.fonts` holds the value in force: the `fonts` option, or the value you last passed to `setFonts()`. To add faces without dropping the host's origins, compose them with `withFontOrigin()`. The added origin comes after the current fonts, so it serves only the faces they leave open.

```ts
import { withFontOrigin } from '@pptx-editor.dev/core/editor';

await editor.setFonts(withFontOrigin(editor.fonts, { sources: localFaces }));
```

`PptxEditor.FontNotice` uses this path for the fonts on the user's computer.

## Limits

Embedded fonts must permit installable or editable embedding. Restricted, preview-and-print-only, and bitmap-only faces are not loaded, including in viewer mode. Save preserves their original bytes and relationships.

- Deck font names never authorize remote requests. The editor never fetches by itself.
- Host bytes pass the content hash, the sfnt check, `maxFontBytes`, the 64 MiB face limit, 256 faces, and 128 MiB in total.
- Replacing the deck or destroying the editor cancels outstanding resolution and discards late answers.
- Missing coverage can change line breaks. A font command can succeed before its bytes arrive.
- The fidelity harness loads only open fonts for the fixtures, not host origins. It fails a deck when the printed PDF draws with any other font.
