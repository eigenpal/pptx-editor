This page lists the layout parts and their props. For the tasks, see [Layout](/docs/customization/layout).

## Layout parts

| Part | What you can change | Notes |
| --- | --- | --- |
| `PptxEditor.Toolbar` | Position, controls, groups, and overflow. | The flat form of the chrome groups. See [Toolbar](/docs/customization/toolbar). |
| `PptxEditor.Ribbon` | Tabs, the selected tab, and each tab's groups. | The tabs over the same chrome groups, with contextual tabs. See [Ribbon](/docs/customization/ribbon). |
| `PptxEditor.Menu` | Position, menus, and rows. | The menu bar. In Vue, `PptxEditorMenu`. See [Menus](/docs/customization/menus). |
| `PptxEditor.Viewport` | `className`, `label`, and children. | Carries `.pptx-editor`, and `dark` with a dark color mode. It is a landmark region named **Presentation editor**. `label` gives another name, as text or a translation key. `label={false}` removes the region. |
| `PptxEditor.Content` | `className`. | The slide canvas and its context menu. |
| `PptxEditor.SlideRail` | `open`, `defaultOpen`, `onOpenChange`, `paneWidth`, `toggle`, `orientation`, `preset`, `t`, `className`, `style`, and part children. | The slide thumbnails, as a column or as a row. The **Hide thumbnails** button hides the rail to a strip with a **Show thumbnails** button. |
| `PptxEditor.NotesPane` | `open`, `defaultOpen`, `onOpenChange`, `showFormatButtons`, `className`, `style`. | The speaker notes of the current slide. Shares its open state with `useNotesPane()`. Use one per root. `showFormatButtons={false}` removes the **B**, **I**, and **U** buttons. The shortcut keys still format the notes. |
| `PptxEditor.SlideSorter` | `className`. | The Slide Sorter view: every slide as a tile, grouped by section. Render it in place of the rail, the canvas, and the notes while `presentationView` is `slideSorter`. Without a mounted sorter in that view, a development warning says so. |
| `PptxEditor.SidePanel` | `onClose`, `tab`, `onTabChange`, `panes`, `paneWidth`, `className`, `style`. | The **Format** tab with selection-specific appearance, content, geometry, and arrangement controls, the **Chart** tab with the type, elements, colors, and data of the selected chart, which shows while a chart is selected ([Charts](/docs/guides/charts#use-the-chart-tab)), the **Selection** tab with the selection pane, the **Animations** tab with the slide transition and the effects of the slide ([Animations and transitions](/docs/guides/animations)), and a **Comments** tab. The tabs show icons, and the selected tab also shows its label. `panes` replaces the content of a tab by tab name (a named slot per tab in Vue). Pass `PptxEditorReview` from `@pptx-editor.dev/pro/react` or `/vue` as the **Comments** content ([Comments](/docs/pro/comments)); without it, the tab says that comments are kept when you save. Render it to show it. Remove it to hide it. Set `tab` and `onTabChange` (`v-model:tab` in Vue) to control the tab. It turns to the tab that `requestPane` asks for. Without `tab`, it starts on **Format**. |
| `PptxEditor.SelectionPane` | `className`. | The objects of the current slide as a tree: select, show or hide, rename, and reorder them. See [Open the selection pane](/docs/customization/layout#open-the-selection-pane). |
| `PptxEditor.ZoomPill` | `className`. | A floating zoom control, placed in the nearest positioned ancestor. |
| `PptxEditor.StatusBar` | `className`, `preset`, `t`, and children. | A row with **Slide x of y**, **Notes**, the view switch, and the zoom pill. See [Status bar](/docs/customization/ribbon#status-bar). |
| `PptxEditor.FindBar` | `className`, `t`. | The find and replace bar, placed in the nearest positioned ancestor. Without it, Find and Replace stay disabled with a reason. |
| `PptxEditor.Slideshow` | None. | The slide show. Mount it once inside the viewport. It shows nothing until a show starts. |
| `PptxEditor.FontNotice`, `PptxEditor.EditNotice` | `className`, `t`. | The font substitution notice, and the edit notice. The edit notice shows the reason the last edit was refused, or what the last Delete removed, with an Undo button. Both float in the nearest positioned ancestor. |
| `PptxEditor.Loading` | `overlay`, `when`, `indicator`, `className`, `style`, and children. | A slide-shaped sheet with a spinner. See [Loading screen](#loading-screen). |
| `PptxEditor.OpenFailure` | `title`, `message`, `showCode`, `actions`, `closeLabel`, `showClose`, `onDismiss`, `className`, `style`, `t`. | The notice for a file that does not open, placed in the nearest positioned ancestor. `<PptxEditor>` renders it. A composed editor adds it. See [Open failure](/docs/customization/layout#open-failure). |

### Status bar parts

The `PptxEditor.StatusBar` parts are `StatusBar.SlideNumber`, `.Notes`, `.Views`, and `.Zoom`. `StatusBar.Action` is your own button. Each part takes `className` and `hidden`. A part child replaces its part in place. Other children go after **Notes**. `preset={false}` shows only the children. In Vue, `PptxEditorStatusBar` has the same four parts as statics, and each takes `className` (or a host `class`).

### Loading screen

`PptxEditor.Loading` shows while the editor has no deck and while a deck opens. The engine paints it before it parses a large deck. `overlay` pins it over the nearest positioned ancestor, so it covers the previous deck. `indicator` replaces the spinner. Children replace the sheet. `PptxEditor.Loading.Spinner` is the packaged spinner. A refused file clears it. In Vue, use `PptxEditorLoading` with the `indicator` and default slots. `PptxEditorLoading.Spinner` is the packaged spinner.

## Pane configuration

Use these props to control the pane:

| Prop | Value | Behavior |
| --- | --- | --- |
| `defaultOpen` | Boolean | `true` by default. The first state, uncontrolled. |
| `open`, `onOpenChange` | Boolean and callback | Controlled open state. Accept each change in your state. |
| `paneWidth` | Pixels | The width of the slide rail or the side panel. For a horizontal rail, the width of the row. The notes pane does not take it. |
| `orientation` | `vertical` or `horizontal` | Slide rail only. `vertical` by default. See [Horizontal slide rail](/docs/customization/layout#horizontal-slide-rail). |
| `toggle` | Boolean | Slide rail only. `false` removes the **Hide thumbnails** and **Show thumbnails** buttons, for a host that opens and closes the rail from its own chrome. A closed rail with `toggle={false}` renders nothing. |
| `className` | CSS class | Styles the pane. |
| `style` | Inline styles | Styles the pane. A `width` in `style` wins over `paneWidth`. |

The rail's `toggle` takes no part props. The rail has two toggle buttons in two places, so one set of props would not say which to change. Change the **Hide thumbnails** button with the `SlideRail.Collapse` part. Change the **Show thumbnails** button of the folded strip with the `SlideRail.Expand` part.

A notes pane fills the height that you give it. Set a `height`, or a `flex` value in a flex column, on the pane's `className`, and the notes field grows into it. A short pane shrinks the field to 40 pixels. Without a height from you, the field keeps its own 96 pixels.

Without `open`, the notes pane reads the open state that `PptxEditor.Root` keeps. A notes pane with `open` gets a change from `useNotesPane()` through its `onOpenChange`. Render one notes pane in each root: a second one keeps its own state and prints a development warning.

### Horizontal rail hooks

| Hook | Use |
| --- | --- |
| `--pptx-rail-thumb-width` | The thumbnail width, `112px` by default. Set it on your rail class or an ancestor. |
| [Slide rail parts](/docs/customization/layout#slide-rail-parts) | The slide actions. The row keeps two rows: its column count is half the buttons that show, rounded up. To remove **Hide thumbnails**, pass `toggle={false}`. |

## Formatting sections

`FormatPanel` follows the editor selection inside an existing root.
`sections` accepts an ordered array of `FormatSectionId` values.
The default includes all applicable sections.
Its order follows the selected object's main editing tasks.
An explicit `sections` array overrides that order.

| Identifier | Controls |
| --- | --- |
| `fill` | Shape fill and styles |
| `line` | Outline color, width, dash, and endpoints |
| `effects` | Supported shape and text effects |
| `picture` | Picture replacement, crop, corrections, recolor, transparency, reset, and alternative text |
| `text` | Character formatting and links |
| `paragraph` | Paragraph formatting, lists, direction, columns, and text fitting |
| `table` | Table styles, cells, borders, and structure |
| `chart` | Chart formatting and data |
| `diagram` | Supported diagram text and structure editing |
| `equation` | Equation editing |
| `arrange` | Order, alignment, rotation, grouping, and ungrouping |
| `geometry` | Size, position, rotation, and applicable object settings |
| `slide` | Slide layout and background |

React's `sectionContent` maps section identifiers to replacement content.
A `null` value hides that section.
Vue provides the same identifiers as named slots.
Replacements apply only when a section is applicable and included in `sections`.

`className` adds a class to the panel.
React children and Vue's default slot append custom content.
Existing whole-tab replacement remains available through `SidePanel`.

`FORMAT_SECTIONS` provides the built-in definitions.
`formatSectionsOf(snapshot, sections?)` returns applicable definitions in the requested order.
`FormatSection` renders one definition through its `section` prop.
These exports let you reuse packaged controls in your own panel.
Commands retain their capability checks when rendered separately.

### Section expansion

Built-in sections use keyboard-accessible disclosure controls.
Expansion preferences belong to the editor instance and selection category.
They survive panel remounts and document replacement within that instance.
They do not change the document, undo history, or collaboration state.
Preferences belong to that editor object. Discard the object after destroying the editor.

Use these core editor helpers when you build custom disclosure controls:

| Helper | Behavior |
| --- | --- |
| `formatSelectionCategory(snapshot)` | Returns the category used for primary tasks and expansion preferences. |
| `formatSectionOpen(editor, category, id)` | Reads the preference or the built-in default. |
| `setFormatSectionOpen(editor, category, id, open)` | Changes one preference without editing the presentation. |
| `listenFormatSectionExpansion(editor, listener)` | Observes preference changes. Call its returned function when your control unmounts. |

`FormatSection` uses these preferences even when rendered outside `FormatPanel`.
Replacement content owns its own disclosure state unless it uses these helpers.

## Pane state attributes

The slide rail and the notes pane carry `data-open="true"` or `data-open="false"`, so your CSS can follow the open state. The slide rail also carries `data-orientation`. Their built-in toggles carry `aria-expanded`, and `aria-controls` names the pane content while it is open.

## Root configuration and lifetime

| Prop | Behavior |
| --- | --- |
| `document` | The `.pptx` bytes. An identity change loads the new document. |
| `mode` | `edit` or `view`. Changes apply without a reload. |
| `locale` | The UI catalog. |
| `colorMode` | `light`, `dark`, or `system`. See [Appearance](/docs/customization/appearance). |
| `popups` | Render overrides for dialogs and popups. See [Dialogs](/docs/customization/dialogs). |
| `fonts`, `onFontError` | Font bytes for the host's faces, and font failures. In Vue, listen to the `fontError` event. See [Fonts](/docs/customization/fonts). |
| `fontFamilies` | The extra families the font picker offers. |
| `onReady`, `onChange` | The instance, once, and every change of editor state. In Vue, listen to the `ready` and `change` events. |

## Open-failure options

Pass options as the `openFailure` object on `PptxEditor`, or as props of `PptxEditor.OpenFailure`:

| Option | Default | Effect |
| --- | --- | --- |
| `title` | `openFailure.title` | The notice title. |
| `message` | The message for the `reason` | Content, or a function of the `DocumentOpenFailure`. In Vue, the `message` slot wins over it. |
| `showCode` | `true` | Shows the error code. |
| `showCopy` | `true` | Shows **Copy details**, which copies the `openFailureReport()` text for a support request. |
| `actions` | None | Your own buttons, as a function of the context. In Vue, the `actions` slot wins over it. |
| `closeLabel` | `openFailure.close` | The **Close** label. |
| `showClose` | `true` | Shows **Close**. |
| `onDismiss` | None | Runs after any close. In Vue, listen to `dismiss`. |
| `className`, `style` | None | Styles the notice element. |

The notice uses the `.pptx-open-failure` class, with `data-reason` set to the failure's `reason`.

### Error codes

`snapshot().openFailure` holds the shown refusal: a `DocumentOpenFailure` with a stable `code` and a `reason`, or `null`. Each refusal is a new object, so a repeated refusal of the same file shows the notice again. The `reason` groups the codes and picks the message:

| `reason` | Codes | Message key |
| --- | --- | --- |
| `damaged` | `zip`, `xml`, `no-content-types` | `openFailure.reasons.damaged` |
| `not-pptx` | `not-a-presentation`, `empty` | `openFailure.reasons.notPptx` |
| `too-large` | `too-many-parts`, `zip-entry-limit`, `zip-size-limit`, `xml-size-limit`, `xml-depth-limit`, `xml-element-limit` | `openFailure.reasons.tooLarge` |
| `blocked` | `xml-dtd-forbidden` | `openFailure.reasons.blocked` |
| `unknown` | `failed` (the open threw), and any other code | `openFailure.reasons.unknown` |

To change a message in every editor, override its key in `locale`.

## React and Vue reference

The Vue adapter has the root, the viewport, the content, the toolbar, the loading screen, the find bar (`PptxEditorFindBar`), the slide show (`PptxEditorSlideshow`, `useSlideshow`), and the font and edit notices (`PptxEditorFontNotice`, `PptxEditorEditNotice`). It has the panes too: `PptxEditorSlideRail`, `PptxEditorSlideSorter`, `PptxEditorNotesPane` (which shares its open state with `useNotesPane`), `PptxEditorSidePanel`, `PptxEditorSelectionPane`, and `PptxEditorZoomPill`.

A pane's `onOpenChange` is the `update:open` event, so `v-model:open` controls it. Each part takes `className`, and `style` where React has it. A host `class` and `style` also work. `PptxEditorSidePanel` takes `onClose` as a prop, as in React: with it, the panel shows its close button.

In Vue, the slide rail parts are statics of `PptxEditorSlideRail` (`PptxEditorSlideRail.AddSlide`, and so on). They are also exported as `SlideRailAddSlide`, `SlideRailChooseLayout`, `SlideRailDuplicate`, `SlideRailMoveEarlier`, `SlideRailMoveLater`, `SlideRailDelete`, `SlideRailCollapse`, and `SlideRailExpand`. Put them in the default slot. `icon` takes a VNode.
