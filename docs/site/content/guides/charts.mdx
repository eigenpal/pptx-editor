A PPTX chart is a graphic frame that names a chart part (`c:chartSpace`, ECMA-376 Part 1, 21.2). The chart part caches the values of every series. The free engine shows a labeled placeholder for a chart. The drawing module of `@pptx-editor.dev/pro` draws the chart from those cached values. It uses the EigenPal Pro License. Evaluation is permitted. Production use requires a commercial agreement.

## Enable chart rendering

```ts
import { createPptxEditor } from '@pptx-editor.dev/core/editor';
import { drawingModule } from '@pptx-editor.dev/pro/drawing';

const editor = createPptxEditor({ document: bytes, modules: [drawingModule({ licenseKey })] });
```

In the React or Vue adapter, pass the same module in the `modules` prop of `PptxEditor`. For headless layout, call `installDrawing({ licenseKey })` once. The module serves every editor in the process, so install it before the first deck opens. `@pptx-editor.dev/pptx-to-pdf` always installs it.

## What draws

- Bar and column charts: clustered, stacked, and percent stacked.
- Line, area, scatter, pie, doughnut, and radar charts.
- Titles, legends, axes, gridlines, data labels, and number formats.

Right legends, top and bottom legends of one row, and radar labels keep their spacing at text sizes from 9 to 20 pt.

3-D, of-pie, stock, bubble, and surface charts, and charts with trendlines or error bars, show the placeholder. The PDF export reports them with the `frame.chart` diagnostic code.

## How it works

The module turns a chart into shapes and labels in the chart's frame. The engine lays them out with the same geometry and text measurement as every other shape. The editor and the PDF export draw that one layout, so the two agree.

A chart selects, moves, and deletes as one object. You can insert a chart, change its type and elements, and edit its data. Inserting and editing are part of the free engine and the React and Vue adapters. The Pro drawing module only draws the result.

## Insert a chart

Choose **Insert** > **Chart**, or the **Chart** button of the toolbar's insert group, and then pick a type: **Column**, **Bar**, **Line**, **Area**, **Pie**, **Doughnut**, or **Scatter**. The new chart fills the empty content placeholder that is selected or holds the cursor, or else the first one. An empty content placeholder also shows a chart button in its middle, which inserts a column chart there. On a slide with no such placeholder, the chart is centered below the title area. When another chart, table, or picture covers that place, the new chart starts 5% of the slide down and to the right of it, so each chart shows its own corner. The chart is selected, and the side panel opens on its **Chart** tab, where you replace the sample data.

From code, run `insertChart` with any `ChartType`. Without `data`, the chart gets three series over four categories of sample values, or one series for a pie or doughnut chart. The sample names follow the editor's language.

```ts
const result = editor.exec({
  type: 'insertChart',
  chartType: 'columnClustered',
  data: {
    categories: ['Q1', 'Q2', 'Q3', 'Q4'],
    series: [
      { name: 'Plan', values: [42, 35, 51, 28] },
      { name: 'Actual', values: [38, 41, 47, null] }, // null is a blank cell
    ],
  },
});
if (!result.ok) console.warn(result.reason); // a translation key
```

A scatter chart's categories are its X values, so each one must be a number. The new chart has an embedded workbook with the same data, so applications that edit chart data in a spreadsheet show your values.

## Change the type and the chart elements

The **Chart** tab of the side panel shows these sections above the data:

- **Chart type** lists every `ChartType`. A chart of another type, such as a 3-D chart, shows **Other type** until you pick one. When the chart has colors or axis titles that you set, a hint says that some types cannot keep them. After such a change, a note says what was removed. A later change to a type that can keep them gives them back, and so does **Undo**. A pie chart draws only its first series, and says so when the data has more.
- **Chart elements** turns the **Title**, **Data labels**, **Axes**, and **Gridlines** on and off, sets the title text, places the **Legend** (none, top, bottom, left, or right), and sets the axis titles. Leave an axis title empty for no title. While **Axes** is off, the axis title fields are unavailable. The gridlines stay as you set them. A pie or doughnut chart has no axis fields.
- **Colors** sets the color of each series, or of each slice of a pie or doughnut chart. **Automatic** gives back the color of the chart style.

A check box, list, or color applies when it changes. A text field applies when you press Enter or leave it. Each change is one undo step.

From code, `editor.chartFormat(nodeId?)` reads the type, elements, and colors of the selected chart. `setChartType`, `setChartFormat`, and `setChartColor` change them:

```ts
editor.exec({ type: 'setChartType', chartType: 'lineMarkers' });
editor.exec({
  type: 'setChartFormat',
  format: { title: 'Sales', legend: 'right', dataLabels: true, valueAxisTitle: 'Units' },
});
// Series 2 in the theme's sixth accent; `null` gives back the automatic color.
editor.exec({ type: 'setChartColor', index: 1, color: { theme: 'accent6' } });

const read = editor.chartFormat();
if (read.ok) console.log(read.format.type, read.format.colorsBy);
```

A field of `setChartFormat` that you leave out keeps its value. A `title` of `null` removes the title. A new title text keeps the font of the old title. `ChartFormat.colorsBy` is `point` for a pie or doughnut chart: `setChartColor` then colors the slice at `index`.

A type change keeps each series' name, data, and color, and the chart's title, legend, and data labels. Markers, trendlines, error bars, and 3-D views that the new type does not have go away. The axes stay when the new type plots on the same kind of axes. Otherwise the chart gets new axes.

## Edit chart data

You can change the series names, the category labels, and the values of a chart. You can also add and remove series and categories.

The data of bar, column, line, area, pie, doughnut, radar, and scatter charts is editable. In a scatter chart, the categories are the X values.

### Use the Chart tab

Select a chart. Then choose **Edit chart…** on the chart toolbar group, on the **Chart Design** ribbon tab, or in the chart's context menu. The side panel opens on its **Chart** tab, beside the slide. The tab shows while a chart is selected. Below the type, elements, and colors, it shows the data:

- **Categories** lists a field for each category label, or **X values** for a scatter chart. Each row has a remove button. **Add category** adds a category at the end.
- **Series** shows a card for each series, with its name and a value field for each category. A card opens and closes with its title. **Add series** adds a series at the end, and **Remove series** removes the series of its card.
- A field applies when you press Enter or leave it. Each applied field, add, or remove is one undo step, and the slide updates at once.
- An empty value field is a blank value. Text that is not a number stays in the field with a reason, and Escape restores the chart's value.

Removing categories or series, changing their labels, or selecting another chart clears uncommitted fields. Appending categories or series preserves drafts in existing cells. Clearing a draft keeps the field focused when that field remains in the grid. This prevents a draft from moving to another data cell.

Every field has a label with its series and category, such as "Plan, North". The tab uses plain form fields, so Tab and Shift+Tab move through it.

The controls send `requestPane(editor, 'chart')`. When your layout can hide the side panel, listen for the request and show the panel. See [Open the side panel from the toolbar](/docs/customization/layout#open-the-side-panel-from-the-toolbar).

### Edit data from code

`editor.chartData(nodeId?)` reads the data of the selected chart, or of a chart frame on the current slide. `setChartData` writes new data. `editor.snapshot().chart` tells you whether the selected chart is editable.

This example renames the first series and adds a category to the selected chart:

```ts
const read = editor.chartData();
if (!read.ok) throw new Error(read.reason); // a translation key

const { kind, categories, series } = read.data;
const result = editor.exec({
  type: 'setChartData',
  data: {
    kind,
    categories: [...categories, { label: 'Central' }],
    series: series.map((s, i) => ({
      ...s,
      name: i === 0 ? 'Budget' : s.name,
      values: [...s.values, 40],
    })),
  },
});
if (!result.ok) console.warn(result.reason);
```

The `source` of each series and category tells the engine where it came from. Keep `source` when you reorder or edit an item, so its formatting stays with it. Leave `source` out for a new item. A new series gets automatic formatting.

### What changes on save

One edit changes the chart part and the embedded workbook together:

- The cached values and the point counts of each series.
- The cell references (`c:f`) of the series names, categories, and values.
- The data point formatting (`c:dPt`) and the data labels (`c:dLbl`). They move with their category, and those of a removed category go away.
- The cells of the embedded workbook. A table in the workbook grows or shrinks with the data.

`ChartData.workbook` says what an edit does to the workbook:

| Value | What an edit does |
| --- | --- |
| `embedded` | The embedded workbook gets the new cells. |
| `kept` | The workbook keeps its old cells. This happens when its data cells have formulas or merged cells, when the chart's references name no sheet of the workbook, or when a table holds series in rows, has a total row, has no header row, or has filters, sorting, or column formulas. |
| `external` | The chart links to another file. The engine never opens it, and turns off its automatic update (`c:autoUpdate`). |
| `none` | The chart has no workbook. |

`workbook` describes the chart's data as it is now. An edit of an `embedded` workbook writes the workbook too, or is refused with `errors.chartData.workbook`. That happens when a series in a workbook table gets an empty name or the name of another series, or when a grown table would cover cells that hold content. So the chart and an `embedded` workbook never disagree.

When the workbook is `kept` or `external`, the tab shows a note. An application that rebuilds the chart from its workbook can show the old values.

### Limits

- Bubble, stock, surface, of-pie, and combination charts stay read-only.
- Charts with filtered series, multi-level categories, or series with different categories stay read-only.
- When the cell references do not form one table, you can change only names, category labels, and values.
- A chart edits up to 255 series and 4,000 categories. Names and labels have up to 255 characters.
- Date categories show as serial numbers.
- The type, elements, and colors of the read-only charts above are not editable either.
- Chart styles, fonts, number formats, axis scales, and the formatting of one data label are not editable.
- A changed chart part keeps its chart style (`c:style`). A new chart has the automatic look of the theme.
