A PPTX chart is a graphic frame that names a chart part (`c:chartSpace`, ECMA-376 Part 1, 21.2). The chart part caches the values of every series. The free engine shows a labeled placeholder for a chart. The drawing module of `@pptx-editor.dev/pro` draws the chart from those cached values. It uses the EigenPal Pro License. Evaluation is permitted. Production use requires a commercial agreement.

## Enable chart rendering

```ts
import { createPptxEditor } from '@pptx-editor.dev/core/editor';
import { drawingModule } from '@pptx-editor.dev/pro/drawing';

const editor = createPptxEditor({ document: bytes, modules: [drawingModule({ licenseKey })] });
```

In the React or Vue adapter, pass the same module in the `modules` prop of `PptxEditor`. For headless layout, call `installDrawing({ licenseKey })` once. The module serves every editor in the process, so install it before the first deck opens. `@pptx-editor.dev/pptx-to-pdf` always installs it.

## What draws

- Bar and column charts: clustered, stacked, and percent stacked.
- Line, area, scatter, pie, doughnut, and radar charts.
- Titles, legends, axes, gridlines, data labels, and number formats.

Right legends, top and bottom legends of one row, and radar labels keep their spacing at text sizes from 9 to 20 pt.

3-D, of-pie, stock, bubble, and surface charts, and charts with trendlines or error bars, show the placeholder. The PDF export reports them with the `frame.chart` diagnostic code.

## How it works

The module turns a chart into shapes and labels in the chart's frame. The engine lays them out with the same geometry and text measurement as every other shape. The editor and the PDF export draw that one layout, so the two agree.

A chart selects, moves, and deletes as one object. Only its data is editable. See [Edit chart data](#edit-chart-data).

## Edit chart data

You can change the series names, the category labels, and the values of a chart. You can also add and remove series and categories. Data editing is part of the free engine and the React and Vue adapters. The Pro drawing module only draws the result.

The data of bar, column, line, area, pie, doughnut, radar, and scatter charts is editable. In a scatter chart, the categories are the X values.

### Use the Edit Data dialog

Select a chart. Then choose **Edit data…** on the chart toolbar group, on the **Chart Design** ribbon tab, or in the chart's context menu. The dialog shows the data as a grid:

- The first row holds the series names. The first column holds the category labels, or the X values of a scatter chart.
- An empty cell is a blank value.
- **Add category** and **Add series** insert after the focused cell. **Remove category** and **Remove series** remove the focused row or column.
- **OK** writes all changes as one undo step.

The grid is a `grid` with one tab stop. The arrow keys move between cells. Left and Right move to the next cell at the edge of the cell's text. Enter and Shift+Enter move down and up. Ctrl+Home and Ctrl+End go to the first and last cells. Each cell has a label with its series and category.

To open the dialog from your own control, call `useEditorDialog('chartData').open()`. To replace or turn off the packaged dialog, set the `chartData` entry of `popups`. See [Open a dialog from your control](/docs/customization/dialogs#open-a-dialog-from-your-control).

### Edit data from code

`editor.chartData(nodeId?)` reads the data of the selected chart, or of a chart frame on the current slide. `setChartData` writes new data. `editor.snapshot().chart` tells you whether the selected chart is editable.

This example renames the first series and adds a category to the selected chart:

```ts
const read = editor.chartData();
if (!read.ok) throw new Error(read.reason); // a translation key

const { kind, categories, series } = read.data;
const result = editor.exec({
  type: 'setChartData',
  data: {
    kind,
    categories: [...categories, { label: 'Central' }],
    series: series.map((s, i) => ({
      ...s,
      name: i === 0 ? 'Budget' : s.name,
      values: [...s.values, 40],
    })),
  },
});
if (!result.ok) console.warn(result.reason);
```

The `source` of each series and category tells the engine where it came from. Keep `source` when you reorder or edit an item, so its formatting stays with it. Leave `source` out for a new item. A new series gets automatic formatting.

### What changes on save

One edit changes the chart part and the embedded workbook together:

- The cached values and the point counts of each series.
- The cell references (`c:f`) of the series names, categories, and values.
- The data point formatting (`c:dPt`) and the data labels (`c:dLbl`). They move with their category, and those of a removed category go away.
- The cells of the embedded workbook. A table in the workbook grows or shrinks with the data.

`ChartData.workbook` says what an edit does to the workbook:

| Value | What an edit does |
| --- | --- |
| `embedded` | The embedded workbook gets the new cells. |
| `kept` | The workbook keeps its old cells. This happens when its data cells have formulas or merged cells, when the chart's references name no sheet of the workbook, or when a table holds series in rows, has a total row, has no header row, or has filters, sorting, or column formulas. |
| `external` | The chart links to another file. The engine never opens it, and turns off its automatic update (`c:autoUpdate`). |
| `none` | The chart has no workbook. |

`workbook` describes the chart's data as it is now. An edit of an `embedded` workbook writes the workbook too, or is refused with `errors.chartData.workbook`. That happens when a series in a workbook table gets an empty name or the name of another series, or when a grown table would cover cells that hold content. So the chart and an `embedded` workbook never disagree.

When the workbook is `kept` or `external`, the dialog shows a note. An application that rebuilds the chart from its workbook can show the old values.

### Limits

- Bubble, stock, surface, of-pie, and combination charts stay read-only.
- Charts with filtered series, multi-level categories, or series with different categories stay read-only.
- When the cell references do not form one table, you can change only names, category labels, and values.
- A chart edits up to 255 series and 4,000 categories. Names and labels have up to 255 characters.
- Date categories show as serial numbers.
- Chart formatting, such as colors, axes, and the chart type, is not editable.
