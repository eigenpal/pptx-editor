Choose an export format for your workflow:

| Output           | API                            | Environment    |
| ---------------- | ------------------------------ | -------------- |
| Editable PPTX    | `editor.save()`                | Browser editor |
| One PNG          | `exportSlidePng()`             | Browser        |
| One SVG          | `exportSlideSvg()`             | Browser        |
| PNG files in ZIP | `exportSlidesPngZip()`         | Browser        |
| PDF              | `@pptx-editor.dev/pptx-to-pdf` | Node.js        |

For PPTX downloads and storage, see [Load and save presentations](/docs/guides/loading-and-saving). PDF conversion uses the EigenPal Pro License. Evaluation is permitted. Production use requires a commercial agreement.

## Export the current slide as PNG

Image export takes the session from a `PptxEditorInstance`. This function returns a `Blob` for your download or upload code:

```ts
import { exportSlidePng, type PptxEditorInstance } from '@pptx-editor.dev/core/editor';

export async function currentSlidePng(editor: PptxEditorInstance) {
  if (!editor.save()) {
    throw new Error('The presentation cannot be exported.');
  }
  const session = editor.session;
  if (!session) throw new Error('No presentation is open.');
  return exportSlidePng(session, editor.snapshot().currentSlide, {
    width: 1920,
  });
}
```

The save check completes pending parsing and detects damaged slides before export. It serializes the presentation but does not download it.

The width defaults to 1920 pixels. It must be from 16 to 8192 pixels. The height follows the slide ratio and cannot exceed 8192 pixels.

## Export SVG or a ZIP archive

Use the same session for either format:

```ts
import {
  exportSlideSvg,
  exportSlidesPngZip,
  type PptxEditorInstance,
} from '@pptx-editor.dev/core/editor';

export async function slideAssets(editor: PptxEditorInstance) {
  if (!editor.save()) throw new Error('Export is unavailable.');
  const session = editor.session;
  if (!session) throw new Error('No presentation is open.');
  const slide = editor.snapshot().currentSlide;
  // EMF and WMF pictures convert in the background. Wait for this slide's.
  if (!(await session.picturesReady(slide))) {
    // A picture that did not convert in time exports as a placeholder.
    console.warn('Some pictures export as placeholders.');
  }
  const svg = exportSlideSvg(session, slide);
  const zip = await exportSlidesPngZip(session, { width: 1280 });
  return { svg, zip };
}
```

SVG export returns a string. ZIP export returns bytes with numbered files such as `slide-01.png`.

The editor converts EMF and WMF pictures to PNG in the background, and shows a placeholder until each one is ready. PNG and ZIP export wait for the conversions. `exportSlideSvg()` is synchronous, so call `session.picturesReady(index)` before it. Omit `index` to wait for the pictures of every slide. The wait lasts 30 seconds at most, and then resolves `false`. It also resolves `false` for a slide that does not exist. A picture that is not ready by then exports as the placeholder.

Catch export errors in your UI. Use PNG when you need a fixed raster image. SVG font embedding follows font permissions; another viewer can substitute unavailable fonts.

## Export PDF

Save the edited PPTX bytes and pass them to your server. Follow [PDF export](/docs/export/pdf) for conversion, font configuration, and error handling.

Keep the PDF package in server code. The browser editor and server converter use the same engine layout.
