## Open and save a deck

This component reads a file input, shows the deck in the editor, and downloads the result. The editor reloads when the identity of `document` changes. The ref's `save()` returns the saved package as bytes.

<FrameworkTabs>
<Framework value="react">

```tsx
// App.tsx
import { useRef, useState } from 'react';
import { PptxEditor, type PptxEditorRef } from '@pptx-editor.dev/react';
import '@pptx-editor.dev/core/styles/editor.css';

export default function App() {
  const [bytes, setBytes] = useState<Uint8Array>();
  const editorRef = useRef<PptxEditorRef>(null);

  async function pick(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0];
    if (file) setBytes(new Uint8Array(await file.arrayBuffer()));
  }

  function download() {
    const saved = editorRef.current?.save();
    if (!saved) return;
    const blob = new Blob([saved]);
    const url = URL.createObjectURL(blob);
    const link = document.createElement('a');
    link.href = url;
    link.download = 'edited.pptx';
    link.click();
    URL.revokeObjectURL(url);
  }

  return (
    <div style={{ display: 'flex', flexDirection: 'column', height: '100vh' }}>
      <div>
        <input type="file" accept=".pptx" onChange={pick} />
        <button onClick={download} disabled={!bytes}>
          Download
        </button>
      </div>
      <div style={{ flex: 1, minHeight: 0 }}>
        <PptxEditor ref={editorRef} document={bytes} mode="edit" />
      </div>
    </div>
  );
}
```

</Framework>
<Framework value="vue">

```vue
<!-- App.vue -->
<script setup lang="ts">
import { ref, shallowRef } from 'vue';
import { PptxEditor, type PptxEditorRef } from '@pptx-editor.dev/vue';
import '@pptx-editor.dev/core/styles/editor.css';

const bytes = shallowRef<Uint8Array>();
const editorRef = ref<PptxEditorRef | null>(null);

async function pick(e: Event) {
  const file = (e.target as HTMLInputElement).files?.[0];
  if (file) bytes.value = new Uint8Array(await file.arrayBuffer());
}

function download() {
  const saved = editorRef.value?.save();
  if (!saved) return;
  const blob = new Blob([saved]);
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = 'edited.pptx';
  link.click();
  URL.revokeObjectURL(url);
}
</script>

<template>
  <div style="display: flex; flex-direction: column; height: 100vh">
    <div>
      <input type="file" accept=".pptx" @change="pick" />
      <button :disabled="!bytes" @click="download">Download</button>
    </div>
    <div style="flex: 1; min-height: 0">
      <PptxEditor ref="editorRef" :document="bytes" mode="edit" />
    </div>
  </div>
</template>
```

## Check the options

| Option | React | Vue | Use |
| --- | --- | --- | --- |
| `document` | `Uint8Array` | `Uint8Array` | The `.pptx` bytes. A new array loads a new deck. |
| `mode` | `'edit'` or `'view'` | `'edit'` or `'view'` | Edit the deck, or only show it. The default is `'edit'`. |
| Ready | `onReady(editor)` | `@ready` | Gives you the editor instance. Use `editor.save()`, `editor.exec(command)`, and `editor.snapshot()`. |
| Ref | `ref` (`PptxEditorRef`) | `ref` (`PptxEditorRef`) | The imperative handle. See [Use the ref](#use-the-ref). |
| `colorMode` | `'light'`, `'dark'`, or `'system'` | Same | The color mode of the chrome. The slides keep their own colors. |
| `fonts` | `EditorFontsOption` | Same | Font bytes for layout. See [Fonts](/docs/customization/fonts). |
| Font errors | `onFontError(error)` | `@font-error` | Called for each font that fails to load. |
| `popups` | `PptxEditorPopups` | Same | Replace the editor's dialogs. See [Dialogs](/docs/customization/dialogs). |
| `locale` | `LocaleCatalog` | Same | The UI strings. English when you omit it. |
| `fontFamilies` | `readonly string[]` | Same | Extra families for the font picker. |
| Changes | `onChange(editor)` | `@change` | Called after every change of editor state. |
| `openFailure` | `boolean` or `PptxEditorOpenFailureProps` | Same | The notice for a file that does not open. `false` removes it. See [Open failure](/docs/customization/layout#open-failure). |
| Open-failure actions | `renderOpenFailureActions(context)` | `#openFailureActions` slot | Your own buttons in the notice, before **Close**. |

## Use the ref

`PptxEditor` and `PptxEditor.Root` (`PptxEditorRoot` in Vue) take a ref to a `PptxEditorRef`. The two adapters give it the same members:

| Member | Returns | Use |
| --- | --- | --- |
| `load(bytes)` | `Promise<CommandResult>` | Open other `.pptx` bytes in the same editor. |
| `save()` | `Uint8Array \| null` | The deck as `.pptx` bytes. `null` when no deck is open. |
| `exec(command, options?)` | `CommandResult` | Run an editing command, as `editor.exec`. |
| `snapshot()` | `EditorSnapshot` | The current editor state. |
| `focus()` | `void` | Give the keyboard back to the slide. |
| `getEditor()` | `PptxEditorInstance \| null` | The editor instance, for everything else. |

You can call each member before the editor mounts. Then `load` and `exec` return a refusal with the reason `disabled.noEditor`, `save` and `getEditor` return `null`, and `snapshot` returns an empty snapshot.

`save()` returns `null` when no deck is open. The editor makes no network request: it reads the deck from the bytes you pass, and it never fetches external targets in the file.
